# Cancelling an order

A customer can request cancellation of their own order at any time while it is still in **CONFIRMED** status. Once an order
has already moved to **CANCELLED**, it cannot be cancelled again - there is nothing further to do.

There is no other eligibility rule: cancellation does not depend on how long ago the order was placed, its remarks, or any
other field. The only thing that matters is the order's current status, so always check it via the order-lookup tool before
telling a customer whether their order can still be cancelled.

If a customer asks you to actually cancel an order, do not attempt it yourself - you do not have a tool for that. Tell them
to use the "Cancel order" action in the order-management UI, or contact human support if they need help doing so.
