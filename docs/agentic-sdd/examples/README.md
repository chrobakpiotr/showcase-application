# Maintained Agentic SDD examples

Use the example that matches the uncertainty level you want to test.

| Example | Flow | Purpose |
|---|---|---|
| `INV-LOW-001` | medium feature | Spec Grill + Architecture Grill + real implementation DAG; prototype remains conditional. |
| `INV-CONTENTION-001` | design-only spike | Three-candidate disposable prototype bake-off for an explicit concurrency question. |
| `SHIP-PLATFORM-001` | large/foggy epic | Full expedition: Destination/Ledger/Fog/Frontier -> reconciliation -> to-spec -> design gate -> independent verification contract -> risk-driven to-tasks/TDD seams -> orchestration -> evals. |

All maintained examples live outside active `docs/specs/` / `docs/wayfinder/` until an explicit activation script is run.
Preview scripts do not invoke a model or change application code.
