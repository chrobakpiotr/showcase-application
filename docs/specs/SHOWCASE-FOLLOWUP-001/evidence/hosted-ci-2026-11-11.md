## First real-stack k6 attempt

On 2026-11-11 the owner ran `ITERATIONS=20` and `VUS=2` against a fresh Docker Compose stack with an operator
token. Setup passed: catalog lookup and stock preparation returned 200. The two first concurrent placements
returned 201 and 500, and the script aborted with exit code 108 as designed. The application log showed
PostgreSQL error 23505 on `customer_email_key`: both orders used the same customer email and every order inserts
its own CUSTOMER row. No p95 was recorded. The defect is handled by
[ORDER-CUSTOMER-EMAIL-001](../../ORDER-CUSTOMER-EMAIL-001/spec.md).
